# RWD Designs — Crafting Dreams

Website for RWD Designs, a creative and digital agency in Dubai: logo design, branding, stationery, websites, hosting, SEO, Google Ads and Meta Ads.

- `index.html` — the whole site (no build step)
- `images/` — portfolio images
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` — icons
- `netlify.toml` — Netlify settings (publish directory is the repo root)

The contact form uses Netlify Forms. After the first deploy, turn on email notifications in Netlify: Site configuration → Forms → Form notifications.
